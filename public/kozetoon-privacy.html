Informasi aplikasi

Kebijakan privasi.

Tanggal pembaruan: 10 Oktober 2026 · Pengembang: Atilla Kuncoro Djati

Kebijakan ini menjelaskan penggunaan data oleh aplikasi Android KOZETOON, termasuk versi uji yang menyediakan backup Google Drive. Fitur yang belum tersedia pada versi yang Anda pasang tidak menjalankan pemrosesan data tersebut. Aplikasi Android berjalan lokal di perangkat; akun website yang Anda jalankan sendiri memiliki penyimpanan terpisah.

1. Data di perangkat

KOZETOON menyimpan katalog, bookmark, judul dan chapter yang dibaca, posisi halaman terakhir, chapter yang ditandai selesai, serta waktu perubahan di penyimpanan pribadi aplikasi. Nama profil, foto profil yang Anda pilih dan potong, pengaturan reader, tampilan, banner pilihan, dan pilihan pembaruan katalog juga dapat disimpan lokal.

Chapter yang selesai diunduh untuk dibaca offline disimpan sebagai file di perangkat. Foto profil hanya diproses ketika Anda memilihnya melalui fitur profil. Aplikasi tidak meminta kata sandi akun Google Anda.

2. Akses akun Google dan backup

Backup Google Drive bersifat opsional. Fitur mulai digunakan setelah Anda menekan tombol untuk menghubungkan Google, memilih akun, dan menyetujui izin. Anda tetap dapat memakai katalog dan simpanan lokal tanpa mengaktifkan backup.

Aplikasi meminta identitas akun dan email melalui izin openid dan email, serta izin drive.appdata untuk membaca dan menulis folder data khusus KOZETOON. Email dan identitas akun digunakan untuk menampilkan akun yang terhubung dan memastikan pemulihan memakai akun yang sama. Izin ini tidak digunakan untuk membaca dokumen, foto, atau file lain di Drive Anda.

Salinan backup dapat memuat:

  • Bookmark, termasuk catatan penghapusan bookmark untuk sinkronisasi.
  • Riwayat baca, posisi chapter dan halaman terakhir, serta penanda chapter selesai.
  • Nama dan foto profil pilihan Anda, serta pengaturan reader, tampilan, banner, dan pembaruan katalog.
  • Informasi judul terkait simpanan tersebut agar bookmark dapat dikenali ketika katalog belum lengkap.
  • Pengenal acak instalasi aplikasi dan waktu perubahan untuk menggabungkan salinan dari perangkat Anda.

File gambar chapter offline, database katalog penuh, file APK, dan token akses Google tidak dimasukkan ke salinan backup. Backup disimpan di folder aplikasi yang tersembunyi pada Drive akun Anda. Folder ini bukan folder publik dan tidak dibagikan melalui fitur backup.

3. Penggunaan dan penerima data

Data pribadi digunakan untuk menyimpan pilihan Anda, melanjutkan bacaan, mencadangkan simpanan, dan memulihkan salinan pada akun yang sama. Fitur backup mengirim salinan langsung dari perangkat ke layanan Google melalui HTTPS; fitur ini tidak mengirim salinan bookmark atau riwayat ke server milik pengembang KOZETOON.

KOZETOON tidak menjual data Google atau menggunakan data yang diperoleh melalui Google API untuk iklan, pemasaran, atau pelatihan model AI. Penggunaan dan pemindahan informasi dari Google API mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use.

Google memproses autentikasi dan penyimpanan Drive sesuai Kebijakan Privasi Google. Saat Anda membaca gambar atau memperbarui katalog, aplikasi menghubungi sumber Shinigami dan penyedia gambar terkait. Pemeriksaan atau unduhan pembaruan APK menghubungi GitHub. Layanan tersebut dapat menerima informasi jaringan yang diperlukan, seperti alamat IP, waktu permintaan, dan identitas aplikasi. Kebijakan masing-masing layanan berlaku pada pemrosesan mereka.

4. Penyimpanan, pemulihan, dan penghapusan

Data lokal tersimpan sampai Anda menghapusnya, menghapus data aplikasi, atau mencopot aplikasi. Memasang pembaruan dengan identitas aplikasi dan sertifikat penandatanganan yang sama dimaksudkan untuk mempertahankan data lokal.

Backup dilakukan berkala ketika fitur aktif, izin akun masih berlaku, dan koneksi tersedia. Android dapat menunda pekerjaan latar belakang. Perubahan terbaru belum dianggap tersimpan di Drive sampai aplikasi menunjukkan pencadangan berhasil. Setelah instal ulang, Anda perlu memilih kembali akun Google yang sama; aplikasi membaca dan menggabungkan salinan yang tersedia dengan data lokal. Chapter offline perlu diunduh ulang.

Salinan Drive dapat tetap tersimpan setelah Anda mencopot aplikasi dari HP, memutuskan akun di KOZETOON, atau mencabut izin Google. Salinan milik instalasi atau perangkat lama dapat tetap ada di folder aplikasi. Menghapus bookmark akan dicatat dan diteruskan pada pencadangan berikutnya; tindakan ini tidak menghapus riwayat baca terkait.

Anda dapat:

  • Menekan Putuskan akun di KOZETOON untuk menghentikan backup otomatis. Tindakan ini mempertahankan data lokal dan salinan Drive.
  • Mencabut akses KOZETOON melalui koneksi pihak ketiga akun Google.
  • Menghapus data tersembunyi KOZETOON melalui pengaturan Kelola aplikasi / Manage apps di Google Drive jika salinan tersebut ingin dihapus.
  • Menghapus unduhan chapter melalui Library, atau menghapus data aplikasi melalui pengaturan Android jika seluruh data lokal ingin dihapus.

Jika Anda menghubungkan kembali backup setelah salinan Drive dihapus, data yang masih tersimpan lokal dapat dicadangkan lagi.

5. Keamanan

KOZETOON memakai penyimpanan pribadi aplikasi Android dan HTTPS untuk permintaan backup. Token akses Google digunakan sementara untuk permintaan yang diperlukan dan tidak dimasukkan ke WebView, database KOZETOON, atau salinan backup. Google Play Services mengelola proses izin akun pada perangkat.

Fitur backup belum menerapkan enkripsi tambahan dengan kunci pribadi yang hanya Anda miliki. Keamanan salinan Drive juga bergantung pada keamanan akun Google dan perangkat Anda. Tidak ada sistem yang menjamin penyimpanan atau pemulihan selalu berhasil; gunakan status pencadangan untuk memastikan salinan sudah tersimpan.

6. Perubahan dan kontak

Kebijakan dapat diperbarui ketika fitur atau penggunaan data berubah. Tanggal pembaruan ditampilkan pada halaman ini. Perubahan izin Google yang diperlukan akan tetap melalui persetujuan akun Anda.
